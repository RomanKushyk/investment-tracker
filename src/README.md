# src/ — Application code

Rules for working in this folder. The binding API contracts (types, repository/hook/store signatures, token names) live in **[`docs/archive/build-plan/pinned-contracts.md`](../docs/archive/build-plan/pinned-contracts.md)** (until 2026-08-26 it was `BUILD-PLAN.md` → "Pinned contracts") — follow them exactly; changing one requires updating every consumer plus a `docs/decisions/README.md` entry.

## Hard rules

- **`lib/db.ts` is imported ONLY by `lib/repository.ts`.** Components/hooks consume data exclusively through the repository via the TanStack Query hooks. Machine-enforced by the ESLint `no-restricted-imports` zones in `eslint.config.js`, along with core-imports-only-core (G1).
- **Palette only via `@theme` tokens** (`bg-sidebar`, `text-muted`, …) — no ad-hoc hex in components. Charts take `var(--color-chart-*)` strings from `core/colors.ts` (aliases resolve in `index.css` `@theme`).
- **`--keyboard-inset` has ONE writer: `app/keyboard-inset.ts`**, called once from `main.tsx`, owning that property on the root the way `app/theme.ts` owns `data-theme`. Three surfaces read it — the `/` action bar, the `Dialog` panel's bound *and* centre, and sonner's toast offset — and they read it **from CSS**, so the keyboard moving re-renders nothing. Do not reintroduce a hook: `Dialog` stays mounted while closed (for its exit animation), so a subscription there would put a visual-viewport listener on every dialog in the tree. The `/` bar also publishes its own measured height as `--action-bar-h` while it is up. **The two breakpoints do not line up** — sonner switches offsets at 600px and the app switches shells at 768 — so both of sonner's offsets carry the bar-clearing floor.
- **Secondary text is `text-muted` and nothing else (D68).** Light `--color-muted` is `#696865`, re-derived against `panel` (the reference's `#8b8a86` read 2.88:1 there, against the 4.5 that 9.5–13px body text needs); dark keeps `#9b9a96`. The old `--color-label` is **deleted, not deprecated** — it failed the same surface and solving both landed them on one luminance, so a `text-label` anywhere is a regression, and a new secondary step is a design session, not a token.
- **A window is `core/period.ts` + the `*AsOf` accessors, and nowhere else (A27).** `resolveWindow(option, start, to)` turns a `PeriodOption` into `{from, to, clamped}`, counted back from the LATEST SNAPSHOT rather than from today — today is not a portfolio fact. `quotesAsOf` / `cashAsOf` / `headlineTotalAsOf` are the bounded twins, and the unbounded `latestQuotes` / `latestCash` / `headlineTotal` now DELEGATE to them: one merge, two names. `transactionsIn(txs, window)` is inclusive at both ends and exists so three screens cannot disagree about that. A period means three different things — a FLOW sums over the window, a STOCK is a level at its END, a RETURN needs both ends — and `period.ts` deliberately holds no opinion about which a given figure is. **DEAD SINCE A42, and the sentence was already misleading before that:** all three windowed screens use the bottom-only `transactionsFrom` / `transactionsFromWindow` instead, because clipping the top end makes a row entered since the last saved quote vanish from one screen while every other screen counts it (`yieldTableRowsIn` measured 65 800 against 115 800). `transactionsIn` now has no callers. Left in place rather than deleted — pre-existing, and not A42's to remove.
- **No hard-coded portfolio figures anywhere** — every displayed number derives from stored data (`core/derive.ts`). Placeholders before the data layer exist show "—". **A DATE THAT DIVIDES THE OTHERS IS A FIGURE (A24):** `PORTFOLIO_START` was a literal `'2026-02-03'` until 2026-08-18 and every annualized percentage on `/yield`, `/attributes` and `/overview` divided by it — true of the demo seed and false of every other dataset. It is now `portfolioStart(assets, snapshots, transactions)`, the earliest of the three signals, `undefined` when there is nothing to measure.
- **Two shells, one breakpoint (D66):** `md` = 768px, written as `max-md:`/`md:` in markup and once as a literal in `hooks/useIsDesktop.ts` — they must stay equal. Below it the sidebar is a Radix-`Dialog` drawer and `AppHeader` carries the capital; above it, today's layout plus a collapse control. **44 × 44 is HIT AREA:** `components/ui/tap-target.ts` (`TAP_44`) puts a transparent `::after` around a control without moving its drawn box, and it needs enough SPACING from the caller that two regions never overlap. Only the quote input and `Button` size `md` actually grow (to 44, radius recomputed to 11); `<input>` cannot take the overlay at all, because a replaced element renders no pseudo-element.
- **Shape (D56):** nothing is a capsule. A standalone control takes `round(min(w,h) × 0.26)`; a box nested against a parent's corner takes `outer = inner + gap`; a **segmented control is both** — segment proportional (7), track concentric (`7 + padding`). Surfaces keep 16/20/24. `rounded-full` survives in exactly three places and they are all genuinely round: `AssetAvatar`, `ColorDot`, the decorative blob — a fourth is a regression. **It was four until D131**, which retired the 36px disc behind the logo mark: the new mark is itself a circle, so its roundness is DRAWN (an arc in an SVG) rather than a radius, and there is nothing left to exempt. Heights must be MEASURED in the browser: `text-[11px]` sets a font size, not a line height. `Button` radius lives in its `size` variant and every variant carries `border-[1.5px]` (filled ones transparent) so heights stay isometric.
- **Fonts:** `font-display` (**IBM Plex Sans**) for headings/`.btn`-style buttons/KPI numbers; `font-body` (**JetBrains Mono**, the body default) for everything else — swapped 2026-08-12 for Cyrillic coverage (D54); never write a family name as a literal, the token is the only source — note the sidebar nav pills and currency toggle inherit the mono body font (matches the reference markup).
- Formatting/derivation logic lives in `core/money.ts` / `core/derive.ts` (pure, unit-tested) — never inline in components. Per-screen pure glue lives in `screens/<route>/<route>.ts` and imports core only; both return structured tokens, never assembled prose (D8) — the WORDS live in `i18n/messages.ts` and reach the pure layer as a `Dict` argument, never as a module import. (Until 2026-08-14 they lived in per-topic label modules in the component layer; `date-labels.ts`, `yield-labels.ts` and `schedule-labels.ts` were retired by A10 rather than translated, because a context-split formatter cannot express Contract 0.)
- **Language (Contract 0, D58):** no user-facing string is written in a component — it comes from `i18n/messages.ts`, and a figure comes from `useFormat()`. Formatting follows the LANGUAGE, not the context: `68 702,10` / `68 629,36 ₴` / `+3,08 %` / `12.08.2026` in Ukrainian against `68,702.10` / `₴68,629.36` / `+3.08%` / `12 Aug 2026` in English. Two things are deliberately NOT translated: the danger zone's typed confirmation (it is compared with the dataset name, so translating it makes the button unarmable) and the tokens in `SHARED` in the parity test.
- **Motion (D7):** every interaction animates softly — `transition active:scale-[.97]` on pressables, `animate-in` reveals, keyed route transitions. Standards: `docs/archive/BUILD-PLAN.md` → "Motion & interaction standards". The `prefers-reduced-motion` kill-switch in `index.css` must stay.
