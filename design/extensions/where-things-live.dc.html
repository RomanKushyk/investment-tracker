discard dialog — Dialog, NOT the D17 typed-name AlertDialog

No neg anywhere, and that is deliberate. Nothing is being destroyed, only abandoned (G-4), so the destructive family stays where D25 put it — overdue reminders, the import replace banner, the danger zone, and S3's own delete confirm.
The SAFE option carries the emphasis and the initial focus: Продовжити редагування is primary, Відхилити is ghost. This is the mirror of the delete dialog's footer, where the emphasised right-hand action is the destructive one — the ordering is “rightmost = emphasised”, not “rightmost = confirm”.
Escape trap. G-4 makes Escape open this dialog from edit mode. Escape inside it must close it and return to edit mode — never discard. Radius 24: a surface, and its corner-adjacent children do not hug all four sides (README §4 overlays).

measured The cascade counts are real seed values, not placeholders: 9 transactions carry assetId: 'reit' (1 buy, 6 dividend accruals, 2 reinvests) and REIT has a quote on 174 snapshot days (2026-02-03 → 2026-07-25 daily, plus the partial 27.07). Ukrainian plurals: 9 → транзакцій (many), 174 → дні (few, since 174 mod 10 = 4).
Note the two “edit” words. The header says Редагувати (enter the mode); the row says Змінити (edit this asset). English collapses both to Edit. Do not “unify” them — they are two different verbs doing two different jobs, and Ukrainian is the language that shows it.

why per-entity has no Save
Every path out of a row commits on its own:
· Змінити → AssetForm (edit) → Зберегти зміни → useUpdateAsset → toast Актив оновлено
· Видалити → the confirm above → useDeleteAsset → toast Актив видалено
· + Додати актив → AssetForm (create) → useAddAsset → toast Актив додано

So by the time the eye returns to the header there is nothing left to write, and nothing a Cancel could take back — a Cancel that cannot undo the deletion behind it is a worse lie than a Save that saves nothing (G-2). Готово only leaves the mode. It is primary because it is still the one filled button that says the page is not at rest (D-1a).

The per-entity variant is therefore never dirty, which is why G-4's discard dialog does not apply to it: navigating away from /portfolio in edit mode simply exits.

Chosen over auto-expand because auto-expand makes the control refuse the press, and — since collapsed groups persist — it would rewrite the stored preference on every navigation into the group, so the arrangement would decay on its own.
A collapsed group is therefore zero rows or one, never a surprise. Navigate away and it closes completely.

BARE · VERTICAL

One rule with three consequences: a boxed control acts on the shell, a bare glyph acts on the content it labels. The axis is the half that needs no learning — the sidebar leaves sideways, a group closes downwards. They also never coexist in the same band, and only one of them exists below md.
Names differ too, for assistive tech: Згорнути навігацію for the shell (existing), Згорнути {group} / Розгорнути {group} for the group. The visible labels do not change.
