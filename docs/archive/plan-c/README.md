decision, so `PLAN-OPEN.md` carries a Status row for each and there was never a detail section under
it. `O20-O23.md` is named for the range it spans, not for four sections.

**`O27.md` and `O28.md` are named for one question each, and that is not a
departure** — the range files are named for what they hold, and these hold a
single body apiece. Both also carry a claim their ruling found wrong; each
header says which, and says why it is not corrected in place. `O28.md` carries a
second oddity worth knowing before reading it: **its body argues for a direction
the owner reversed**, so it is evidence of what was believed on 2026-08-25 and
not of what was decided.
