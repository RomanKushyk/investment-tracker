## D58 — Formatting follows the language, and the type system cannot see most of it (2026-08-14)

**Phase 5, A10.** Ukrainian is the default language; English is the second.

### Contract 0 reverses the plan that preceded it

`NEXT-PHASE-PLAN` had pinned formats as byte-identical in both languages. The
phase-5 design session ruled the opposite — *"formatting separates completely per
language, with no exceptions"* — and D14 gives the brief copy and behaviour
disputes, so the plan line was stale, not the brief.

| | Ukrainian | English |
|---|---|---|
| Number | `68 702,10` | `68,702.10` |
| Money | `68 629,36 ₴` | `₴68,629.36` |
| Percent | `+3,08 %` | `+3.08%` |
| Date | `12.08.2026` | `12 Aug 2026` |

Three details are decisions rather than lookups: the Ukrainian thousands
separator is U+00A0 or a figure wraps mid-number; Ukrainian puts a space before
`%` per ДСТУ; English dates are `12 Aug 2026` rather than a slashed form, which
is ambiguous between British and American reading.

The formatter is therefore bound, not global. `core/` is pure and may not read
state (G1), so the language is a PARAMETER: `makeFormat(lang)` behind
`useFormat()`. A module global would also have frozen every figure at the value it
had when the module loaded — the language switch has to re-render them.

### The dictionary is typed, and the tests cover what the type cannot

`en` is canonical, `type Dict = typeof en`, `uk: Dict`. The type catches a missing
key and a wrong shape. It cannot see: a key copied across untranslated, an
interpolation dropped from a translated function, or a value that is deliberately
identical. So the runtime test asserts each of those — a `SHARED` allowlist
carries the deliberate ones (`DEMO`, each language naming itself, `XIRR`, a
whole-number placeholder), and interpolations are FUNCTIONS, not placeholder
strings, so their arity is typed and a distinctive marker fed in must come back
out.

### A green suite is not a translated app

The sweep took three scans, and the third found most of what was left: JSX text
nodes, then string literals, then template literals — where the prose that
carries a value lives. Everything the first two passes missed was inside
backticks or inside `{…}` expressions. What proved it each time was rendering the
page and reading it, not the tests.

### Two traps worth naming

The danger zone's typed word is DATA, not copy. The confirm compares what the user
types with the dataset name, so translating it would make the button unarmable. It
reads `typeToConfirm(dataset)` and the word is interpolated.

Placeholders follow the language too — they MODEL the input convention. That is
what exposed a real defect: the English placeholder `10,000.00` was rejected by
the very form that offered it, because the parser read every comma as a decimal
mark (`10.000.00` → NaN). The fix needs no locale: when both marks are present the
LAST one is the decimal and the other is grouping.

### What Ukrainian needs that English does not

A genitive month list (`на початку червня`, never `червень`), three-form plurals
with the 11–14 band taking `many`, `і` where English writes `&`, and a
sentence-start capital for a month name that is otherwise lowercase. None of it is
expressible as a lookup of the English string, which is the argument for a
dictionary of sentences over a dictionary of words.
