# infra — console setup, SES, and the Inzhur sanction check

Two roles, deliberately narrow: the GitHub role can only drive CloudFormation on one named stack and hand it the execution role, which alone holds the broad permissions — this is also why CDK is not used here, since its bootstrap execution role is `AdministratorAccess` by default. The OIDC provider already exists from the frontend setup (`docs/reference/DEPLOYMENT.md` §1.4) — do not create a second one. Replace `<account-id>` with the account's own id, deliberately not written down in this public repository. **The DSQL resource stays `cluster/*`** — cluster IDs are generated, not named, so there is no prefix to scope to, and the exec role can therefore reach every DSQL cluster in the account, old ones included; CloudFormation will not touch a cluster outside its own stack, but nothing else stops it either. The trust policy keys on the **environment**, not the branch; owner and repo carry immutable numeric IDs — both documented at length in `docs/reference/DEPLOYMENT.md` §1.5.

**SES has no CloudFormation of its own.** What exists: the verified domain `quirenote.com` (Easy DKIM, custom MAIL FROM `mail.quirenote.com`, SPF on it, DMARC `p=none`), and configuration set **`quirenote-mail`** — the identity's DEFAULT set — with an event destination `problems-to-eventbridge` sending BOUNCE, COMPLAINT, REJECT, DELIVERY_DELAY and RENDERING_FAILURE to the default EventBridge bus, the same channel the alarms use (`docs/DECISIONS.md`, **Alerting**). The account is in the **sandbox**: 200 messages/day, 1/s, verified recipients only.

**Reading the Inzhur feed is sanctioned** — checked against ТОВ «ІНЖУР КЕПІТАЛ»'s client agreement and `https://www.inzhur.reit/robots.txt`: the deny list excludes `/dashboard/`, `/signin/`, `/signup/`, `/documents`, `/fund_merger_report`, `/annual_report_2025`, `/terms` and `/privacy-policy` — not `/_api/`. No clause in the contract prohibits automated access, and its confidentiality clause carves out information obtainable from public sources.
